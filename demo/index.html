当前页面：仪表盘

本页模拟真实 ERP 侧边栏与顶栏 DOM，供商店审核员验证扩展功能。无需账号。

  1. 安装扩展 ERP Menu Layout Modifier
  2. 刷新本页面
  3. 确认左侧深色侧边栏消失，顶部出现蓝色导航，左侧出现子菜单
  4. 确认原白色顶栏（图标/用户下拉）消失，并出现在蓝色插件顶栏右侧（可在扩展弹窗切换左侧/右侧）
  5. 点击顶部不同一级菜单，左侧子菜单应切换
  6. 点击顶栏左侧 ☰ 按钮，左侧子菜单应收起、内容区占满宽度；再次点击应恢复
  7. 点击扩展图标，关闭「启用菜单调整」，应恢复左侧原始菜单与原顶栏
  8. （可选）缩小浏览器窗口，顶部菜单过多时应出现「更多」折叠
Clicking a leaf menu item updates the title above — this simulates ERP navigation without a real backend.
