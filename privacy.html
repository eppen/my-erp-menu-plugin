Product: ERP Menu Layout Modifier
Last updated / 更新日期: 2026-08-17

中文 English

1. 概述

本隐私政策适用于浏览器扩展 ERP Menu Layout Modifier（以下简称「本扩展」），适用于 Microsoft Edge 与 Chromium 内核浏览器。

本扩展的唯一用途是：在指定的 ERP / 演示页面上，将左侧菜单布局调整为顶部一级菜单 + 左侧二级菜单，并提供开关、收藏与搜索等本地辅助功能。

2. 我们收集哪些数据

本扩展不向开发者服务器上传任何数据。不设远程后端，不采集分析统计，不投放广告。

仅保存在浏览器本地 / 同步存储中的偏好

  • 菜单调整开关状态（是否启用布局改造）
  • 收藏的菜单项名称（用户主动收藏的菜单文案）
  • 横向菜单折叠偏好（是否启用「更多」折叠）

上述数据通过浏览器提供的 chrome.storage.sync 保存在用户设备（并可随用户浏览器账号同步）。开发者无法访问这些数据。

页面内容（仅本地处理）

在匹配的网站上，本扩展会读取页面中的菜单 DOM（如菜单标题、结构），以便在本地重组界面。这些内容不会被发送到任何外部服务器。

本扩展不收集：姓名、邮箱、密码、身份证件、支付信息、通讯内容、精确位置、浏览历史上传、健康信息等。

3. 数据如何使用

  • 仅用于实现已声明的菜单布局改造与相关本地功能（开关记忆、收藏、搜索、折叠）。
  • 不用于广告、画像、跨网站跟踪或出售。
  • 不与第三方共享用户数据（除浏览器自身提供的同步机制外，该机制由浏览器厂商管理）。

4. 权限说明

  • storage：保存上述本地偏好。
  • activeTab：在用户与扩展弹窗交互时，向当前标签页通知开关状态。
  • scripting：支持在匹配页面注入布局改造所需的脚本/样式能力。
  • 主机权限（指定 URL）：仅在声明的 ERP 地址、公开 Demo 及本地测试地址上运行内容脚本，不作用于任意网站。

5. 远程代码

本扩展不使用远程代码。所有逻辑均打包在扩展包内，不从互联网动态加载可执行脚本。

6. 用户控制与数据删除

  • 可在扩展弹窗中随时关闭「启用菜单调整」。
  • 可通过浏览器「扩展」页面卸载本扩展；卸载后，扩展写入的本地偏好将随浏览器机制清除或不再使用。
  • 也可在浏览器设置中清除扩展的存储数据 / 同步数据。

7. 儿童隐私

本扩展面向企业内部 ERP 使用场景，不面向 13 岁以下儿童，也不故意收集儿童个人信息。

8. 政策更新

若数据处理方式发生变化，我们将更新本页面的「更新日期」，并在扩展商店资料中同步隐私政策链接。

1. Overview

This Privacy Policy applies to the browser extension ERP Menu Layout Modifier (“the Extension”) for Microsoft Edge and other Chromium-based browsers.

The Extension’s single purpose is to transform a left sidebar menu into a top-level navigation bar plus a left sub-menu on designated ERP / demo pages, with local helpers such as an on/off switch, favorites, and search.

2. What data we collect

The Extension does not upload any data to developer-operated servers. There is no remote backend, no analytics, and no advertising.

Preferences stored only in browser storage

  • Menu modification on/off state
  • Favorite menu item labels (only items the user stars)
  • Horizontal menu collapse preference

These values are saved via chrome.storage.sync on the user’s device (and may sync through the browser vendor’s sync feature). The developer cannot access this data.

Website content (processed locally only)

On matched sites, the Extension reads menu-related DOM (titles and structure) solely to rebuild the UI locally. This content is not transmitted to any external server.

The Extension does not collect names, emails, passwords, government IDs, payment data, message content, precise location, uploaded browsing history, or health information.

3. How data is used

  • Only to provide the declared menu-layout features and related local preferences.
  • Not for advertising, profiling, cross-site tracking, or sale.
  • Not shared with third parties, except browser sync mechanisms controlled by the browser vendor.

4. Permissions

  • storage — save the preferences listed above.
  • activeTab — notify the active tab when the user toggles the feature from the popup.
  • scripting — support injecting the layout scripts/styles on matched pages.
  • Host permissions (specific URLs) — run content scripts only on declared ERP hosts, the public demo, and local test URLs—not on arbitrary websites.

5. Remote code

The Extension does not use remote code. All logic ships inside the extension package; no executable scripts are fetched from the network at runtime.

6. User controls and deletion

  • Turn off menu modification anytime in the extension popup.
  • Uninstall the Extension from the browser’s Extensions page; stored preferences are cleared or unused thereafter per browser behavior.
  • Clear extension storage / sync data in browser settings if desired.

7. Children’s privacy

The Extension is intended for enterprise ERP workflows and is not directed at children under 13. We do not knowingly collect children’s personal information.

8. Changes

If data practices change, we will update the “Last updated” date on this page and keep the store listing privacy URL current.
